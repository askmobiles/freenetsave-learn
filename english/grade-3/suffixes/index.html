Suffixes

A suffix is a small part added to the end of a word: -ful, -less, -er, -ly and -ing.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 3 English.

Learn what you need to know

A suffix goes at the end of a word and changes what it means or how it is used.

💝-ful = full of: helpful, careful, joyful
🕳️-less = without: careless, homeless, endless
👩‍🏫-er = a person who: teacher, painter, singer
🐢-ly = in a way: slowly, quietly, kindly
🏃-ing = doing now: jumping, reading, playing

Spelling tips: happy + ness → happiness (y → i). run + ing → running (double the last letter).

-ful has only one l: helpful, not helpfull!

Key words

  • suffix: a word part added to the end of a word
  • base word: the main word before a suffix is added
  • ending: the last part of a word
