Possessive nouns

Use apostrophes to show who owns something: the dog's bone, the dogs' bones, the children's toys.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 5 English.

Learn what you need to know

🐶One owner: add 's — the dog's bone, Maya's bike
🐶🐶More than one owner (ending in s): add only ' — the dogs' bones, the teachers' room
👧👦Plural not ending in s: add 's — the children's toys, the men's team
🚫Don't use an apostrophe for a simple plural: "two cats" not "two cat's"

Its vs it's: "its" shows ownership (The bird flapped its wings). "It's" means "it is."

Steps: 1) Write the owner word. 2) Does it end in s because it is plural? Add ' only. Otherwise add 's.

Key words

  • possessive noun: a noun that shows ownership
  • apostrophe: a mark (') used to show ownership or a contraction
  • singular: one
  • plural: more than one

See real-life examples

Store signs

"Tim's Bakery" and "Women's Clothing" use possessives.

Name tags

"Kai's locker" shows whose it is.

Mistakes

Signs like "Apple's for sale" use apostrophes wrongly.
