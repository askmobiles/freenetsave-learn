Learn what you need to know

A paragraph is a group of sentences about one main idea. The main idea is often in the first sentence, called the topic sentence.

🎯Main idea: what the paragraph is mostly about
🧱Supporting details: facts, examples or reasons that tell more about the main idea
🚫A detail that doesn't fit belongs somewhere else
↩️Indent the first line of each new paragraph

Think of a table: the main idea is the tabletop, and the details are the legs that hold it up.

Ask: "What is this paragraph mostly about?" That's the main idea.

Key words

  • paragraph: a group of sentences about one main idea
  • main idea: what a paragraph is mostly about
  • supporting detail: a fact, example or reason that tells more about the main idea
  • indent: to start a line a little to the right
