Building a paragraph

Learn what you need to know

🎯Topic sentence: tells the main idea of the paragraph
🧱Supporting details: reasons, facts, examples and explanations (usually 3)
🔗Transitions: first, also, for example, in addition, finally
🏁Concluding sentence: wraps up the idea in new words

Stay on topic. Every sentence should connect to the topic sentence. If a sentence talks about something else, it belongs in a different paragraph.

Example topic sentence: "Owning a dog teaches kids responsibility." Details: feeding, walking, training. Conclusion: "Caring for a dog helps kids grow into responsible people."

One paragraph, one main idea.

Key words

  • topic sentence: the sentence that tells the main idea of a paragraph
  • supporting detail: a fact, reason or example that backs up the main idea
  • transition: a word or phrase that links ideas
  • concluding sentence: the last sentence that wraps up the paragraph
