Sentences with si

Les phrases hypothétiques avec si : les trois types (possible, imaginaire, regret).⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 11 French.

Learn what you need to know

1️⃣Possible : si + présent → futur / présent / impératif. « S'il pleut, je resterai à la maison. »
2️⃣Imaginaire : si + imparfait → conditionnel présent. « Si j'étais riche, je voyagerais. »
3️⃣Regret (passé) : si + plus-que-parfait → conditionnel passé. « Si j'avais étudié, j'aurais réussi. »

Conditionnel passé : avoir/être au conditionnel + participe passé : j'aurais fini, elle serait partie.

Règle d'or : JAMAIS de futur ni de conditionnel après si (dans ce sens). « Si j'aurais » est toujours faux! Si + il → s'il.

Key words

  • une hypothèse: a hypothetical situation
  • le conditionnel passé: would have done
  • s'il: si + il
  • au cas où: in case
