Lequel, laquelle, lesquels

Lequel, laquelle, lesquels, lesquelles : pour demander « which one? » et comme pronoms relatifs après une préposition.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 11 French.

Learn what you need to know

❓Question : J'ai deux stylos. Lequel veux-tu? (stylo = masc.) Voici des robes. Laquelle préfères-tu? Lesquels / lesquelles au pluriel.
🔗Relatif après une préposition : La table sur laquelle j'écris. Le stylo avec lequel je dessine. Les amis pour lesquels j'ai cuisiné.
➕à + lequel = auquel; à + lesquels = auxquels; à + lesquelles = auxquelles (à laquelle ne change pas)
➕de + lequel = duquel; de + lesquels = desquels (souvent après « près de », « à côté de »)

Accord : lequel prend le genre et le nombre du nom qu'il remplace.

Key words

  • lequel: which one (masc.)
  • laquelle: which one (fém.)
  • auquel: à + lequel
  • duquel: de + lequel

See real-life examples

Au magasin

« J'aime ces deux chandails. Lequel est le moins cher? »

Un concours

« Le concours auquel j'ai participé était difficile. »

Une rédaction

« Voici les raisons pour lesquelles je suis d'accord. »
