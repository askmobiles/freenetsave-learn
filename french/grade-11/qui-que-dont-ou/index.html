Qui, que, dont, où

Les pronoms relatifs qui, que, dont et où pour relier deux idées dans une seule phrase.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 11 French.

Learn what you need to know

🟢qui = sujet : J'ai un ami qui parle quatre langues.
🔵que (qu') = objet direct : Le livre que je lis est passionnant.
🟣dont = remplace « de + nom » : Le film dont je parle est sorti hier. (parler de)
🟠où = lieu ou temps : La ville où j'habite. Le jour où je suis né.
🔗Relier : J'ai un chien. Mon chien est noir. → J'ai un chien qui est noir.
🔗C'est une chanson. J'adore cette chanson. → C'est une chanson que j'adore.
🔗Voici l'élève. Je t'ai parlé de cet élève. → Voici l'élève dont je t'ai parlé.

Verbes avec de → dont : parler de, avoir besoin de, avoir peur de, être fier de, se souvenir de.

Key words

  • pronom relatif: relie deux phrases : qui, que, dont, où
  • dont: of which, whose, about which
  • avoir besoin de: to need
  • être fier de: to be proud of
