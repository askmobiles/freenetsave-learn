Possessive pronouns

Les pronoms possessifs : le mien, la tienne, les nôtres… pour éviter de répéter « mon livre », « ta voiture ».⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 11 French.

Learn what you need to know

1️⃣à moi : le mien, la mienne, les miens, les miennes
2️⃣à toi : le tien, la tienne, les tiens, les tiennes
3️⃣à lui / à elle : le sien, la sienne, les siens, les siennes
4️⃣à nous : le nôtre, la nôtre, les nôtres
5️⃣à vous : le vôtre, la vôtre, les vôtres
6️⃣à eux / à elles : le leur, la leur, les leurs

Le genre suit la chose possédée, pas le propriétaire : C'est la voiture de Marc → c'est la sienne (voiture = féminin). Accent circonflexe : le nôtre, le vôtre (pronoms), mais notre, votre (adjectifs).

Key words

  • pronom possessif: remplace possessif + nom
  • le mien: mine (masculin)
  • la sienne: his / hers (féminin)
  • les leurs: theirs

En classe
