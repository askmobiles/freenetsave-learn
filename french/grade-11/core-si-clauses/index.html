Core French: If… then (si clauses)

Learn what you need to know

✅Real possibility: si + present → future. Si il fait beau, nous irons à la plage.
💭Imagined: si + imparfait → conditional. Si j'étais riche, j'achèterais une maison.
🔤si + il = s'il; si + elle stays si elle.
🚫Never put the future or conditional right after si: « Si j'aurais » is wrong.

Pattern to remember: Si + présent → futur. Si + imparfait → conditionnel.

Key words

  • si: if
  • s'il: if he / if it
  • si j'étais…: if I were…
  • une hypothèse: a hypothesis / what-if
