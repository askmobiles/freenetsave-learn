Core French: Regrets (past conditional)

Talk about regrets and missed chances: J'aurais dû étudier. Si j'avais su, je serais venu.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 12 French.

Learn what you need to know

How to make it: avoir or être in the conditional + past participle. J'aurais mangé (I would have eaten). Je serais allé (I would have gone).

😔Regret: J'aurais dû partir plus tôt. (I should have…)
🤷Could have: J'aurais pu gagner. (I could have…)
💭Past "if": Si j'avais su, je serais venu. (If I had known, I would have come.)
🔗Pattern: si + plus-que-parfait (j'avais + participle) → past conditional

Same être verbs as the passé composé: aller, venir, partir, arriver… use être: Elle serait venue.

Key words

  • j'aurais dû: I should have
  • j'aurais pu: I could have
  • si j'avais su: if I had known
  • un regret: a regret
