Reported speech

Le discours rapporté (indirect) : rapporter les paroles de quelqu'un en changeant les pronoms, les temps et les repères de temps.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 12 French.

Learn what you need to know

💬Direct : Elle dit : « Je suis fatiguée. » → Indirect : Elle dit qu'elle est fatiguée.
❓Question oui/non : « Tu viens? » → Il demande si je viens.
❔Question avec mot interrogatif : « Où vas-tu? » → Il demande où je vais. « Qu'est-ce que tu fais? » → ce que je fais.
📢Ordre : « Fermez la porte! » → Il nous dit de fermer la porte.
⏪Si le verbe introducteur est au passé : présent → imparfait; passé composé → plus-que-parfait; futur → conditionnel.
📅Repères : aujourd'hui → ce jour-là; demain → le lendemain; hier → la veille; ici → là.

Exemple complet : Il a dit : « Je partirai demain. » → Il a dit qu'il partirait le lendemain.

Key words

  • le discours direct: quoted speech
  • le discours indirect: reported speech
  • le lendemain: the next day
  • la veille: the day before
