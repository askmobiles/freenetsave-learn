Le, la, l' and les

Les articles définis : le, la, l' et les (the). Chaque nom est masculin ou féminin.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 3 French.

Learn what you need to know

🔵le + masculin : le chat, le livre, le parc
🔴la + féminin : la porte, la pomme, la maison
🟢l' + voyelle ou h : l'école, l'ami, l'arbre, l'hiver
🟣les + pluriel : les chats, les pommes, les amis

Le truc : apprends chaque nom avec son article! Pas « chat », mais « le chat ».

Key words

  • article: un petit mot devant le nom
  • masculin: avec le, un
  • féminin: avec la, une
  • pluriel: plus d'un : les
