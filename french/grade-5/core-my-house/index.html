Core French: My house

Learn what you need to know

🍳la cuisine = kitchen
🛏️la chambre = bedroom
🛁la salle de bain = bathroom
🛋️le salon = living room
🚗le garage
⬇️le sous-sol = basement
📦Il y a… = There is / There are…
🏠J'habite dans une maison / un appartement. = I live in a house / an apartment.

Il y a never changes: il y a un lit, il y a trois chambres.

Key words

  • la maison: house
  • la chambre: bedroom
  • la cuisine: kitchen
  • il y a: there is / there are
