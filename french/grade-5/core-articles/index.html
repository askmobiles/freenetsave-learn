Core French: Le, la, les and un, une, des

Every French noun is masculine or feminine. Learn which little word goes in front.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 5 French.

Learn what you need to know

🔵Masculine: le / un → le livre, un livre (the book, a book)
🔴Feminine: la / une → la table, une table
🟢Before a vowel: l' → l'école, l'ami
🟣Plural: les / des → les livres, des tables

Tip: learn every new word with its little word: not "chat", but "le chat". Words ending in -e are often feminine, but not always!

Key words

  • le / la: the (masculine / feminine)
  • un / une: a (masculine / feminine)
  • les: the (plural)
  • des: some (plural)
