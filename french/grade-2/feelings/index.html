Feelings

Learn what you need to know

😀content / contente — happy
😢triste — sad
😠fâché / fâchée — angry
😴fatigué / fatiguée — tired
😨J'ai peur. — I'm scared.
😲surpris / surprise — surprised
😌calme — calm
🤩excité / excitée — excited

Comment te sens-tu? = How do you feel? — Je suis content. Je me sens fatigué.

Pour les filles, on ajoute souvent un -e : il est content, elle est contente.

Key words

  • content: happy
  • triste: sad
  • fâché: angry
  • fatigué: tired
