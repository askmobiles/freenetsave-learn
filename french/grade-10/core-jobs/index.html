Core French: Jobs and part-time work

Learn what you need to know

👩‍⚕️un médecin, un infirmier / une infirmière, un dentiste
👨‍🏫un enseignant / une enseignante (teacher), un avocat / une avocate (lawyer)
🔧un électricien / une électricienne, un plombier, un mécanicien
🍳un cuisinier / une cuisinière, un serveur / une serveuse, un caissier / une caissière (cashier)
💼un emploi à temps partiel (part-time job), travailler, gagner de l'argent, le salaire
🗣️Je voudrais devenir… (I would like to become…) / Je travaille comme… (I work as…)

No "a" before a job: Elle est infirmière. (She is a nurse.) Not « Elle est une infirmière ».

Key words

  • un emploi: a job
  • à temps partiel: part-time
  • gagner: to earn
  • devenir: to become
