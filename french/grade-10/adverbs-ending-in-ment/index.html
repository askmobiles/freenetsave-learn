Adverbs ending in -ment

Former les adverbes en -ment à partir des adjectifs : lent → lentement, rapide → rapidement.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 10 French.

Learn what you need to know

1️⃣Adjectif féminin + -ment : lent → lente → lentement; heureux → heureuse → heureusement
2️⃣Adjectif qui finit par une voyelle (masculin) + -ment : rapide → rapidement; vrai → vraiment; poli → poliment
3️⃣-ant → -amment : courant → couramment. -ent → -emment : évident → évidemment, récent → récemment
⭐Irréguliers : bon → bien; mauvais → mal; gentil → gentiment; meilleur → mieux

Place : l'adverbe va souvent après le verbe conjugué : Il parle lentement. Au passé composé : J'ai bien dormi.

Key words

  • un adverbe: un mot qui décrit un verbe
  • lentement: slowly
  • heureusement: fortunately
  • couramment: fluently
