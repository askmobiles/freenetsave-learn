Learn what you need to know

🐱le chat — cat
🐶le chien — dog
🐟le poisson — fish
🐦l'oiseau — bird
🐰le lapin — rabbit
🐭la souris — mouse
🐮la vache — cow
🐴le cheval — horse
🐻l'ours — bear
🐸la grenouille — frog

Qu'est-ce que c'est? = What is it? « C'est un chat! » 🐱

Les sons : le chien fait « ouaf », le chat fait « miaou », la vache fait « meuh »!

Key words

  • le chat: cat
  • le chien: dog
  • l'oiseau: bird
  • le lapin: rabbit
