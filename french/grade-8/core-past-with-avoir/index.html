Core French: The past with avoir

Learn what you need to know

Formula: avoir (present) + past participle. Example: j'ai mangé = I ate / I have eaten.

🔵-er verbs → -é: parler → parlé, jouer → joué, manger → mangé
🟢-ir verbs → -i: finir → fini, choisir → choisi
🟣-re verbs → -u: vendre → vendu, attendre → attendu
⭐Tricky ones: faire → fait, voir → vu, lire → lu, boire → bu, prendre → pris, écrire → écrit, avoir → eu, être → été

Negative: ne… pas goes around avoir: Je n'ai pas mangé.

Key words

  • le passé composé: the past tense
  • hier: yesterday
  • le week-end dernier: last weekend
  • déjà: already
