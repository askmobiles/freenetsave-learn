Asking questions

Learn what you need to know

🗣️Intonation (familier) : Tu viens ce soir?
❓Est-ce que (courant) : Est-ce que tu viens ce soir?
🎩Inversion (soutenu, écrit) : Viens-tu ce soir?

Dans l'inversion, on met un trait d'union entre le verbe et le pronom. Si le verbe finit par une voyelle avec il, elle ou on, on ajoute -t- : « Parle-t-il français? » « A-t-elle fini? »

🧑Qui? = who
📦Que / Qu'est-ce que? = what
📍Où? = where
⏰Quand? = when
🤔Pourquoi? = why
🛠️Comment? = how
🔢Combien (de)? = how much / how many
🎯Quel, quelle, quels, quelles? = which / what (s'accorde avec le nom)

Quel s'accorde : quel livre, quelle heure, quels films, quelles chansons.

Key words

  • intonation: la voix qui monte à la fin pour poser une question
  • inversion: verbe avant le sujet : Viens-tu?
  • mot interrogatif: mot qui commence une question : où, quand, pourquoi
  • trait d'union: le petit tiret entre le verbe et le pronom
