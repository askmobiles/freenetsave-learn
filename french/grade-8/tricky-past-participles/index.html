Tricky past participles

Learn what you need to know

Beaucoup de verbes courants ont un participe passé irrégulier. Il faut les apprendre par cœur.

-uavoir → eu, boire → bu, croire → cru, devoir → dû, lire → lu, pouvoir → pu, savoir → su, voir → vu, vouloir → voulu, vivre → vécu, connaître → connu, recevoir → reçu
-is / -itprendre → pris, mettre → mis, apprendre → appris, comprendre → compris, dire → dit, écrire → écrit, conduire → conduit
autresêtre → été, faire → fait, ouvrir → ouvert, offrir → offert, mourir → mort, naître → né

Accord avec avoir (niveau immersion) : le participe passé s'accorde avec le complément direct (CD) s'il est placé avant le verbe.

➡️J'ai mangé les pommes. (CD après : pas d'accord)
⬅️Les pommes que j'ai mangées. (CD avant : accord, -es)
⬅️Ces lettres, je les ai écrites. (les = CD avant)

Question à poser : j'ai mangé QUOI? Si la réponse est avant le verbe, on accorde.

Key words

  • participe passé irrégulier: participe qui ne suit pas les règles -é, -i, -u
  • complément direct: mot qui répond à « quoi? » ou « qui? » après le verbe sans préposition
  • pronom complément: le, la, les, l' qui remplace un complément direct
  • par cœur: appris de mémoire
