Le, la, les as pronouns

Les pronoms compléments d'objet direct : le, la, l', les remplacent une chose ou une personne.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 9 French.

Learn what you need to know

Un complément d'objet direct (COD) répond à la question qui? ou quoi? après le verbe, sans préposition : Je regarde le film. → Je le regarde.

🔵le = masculin : Tu manges le gâteau? → Oui, je le mange.
🔴la = féminin : Il aime la musique. → Il l'aime.
🟣les = pluriel : Elle lit les livres. → Elle les lit.
👥Personnes : me, te, nous, vous aussi : Il m'appelle. Je vous écoute.

Place : le pronom va AVANT le verbe conjugué : Je la vois. Je ne la vois pas. Avec un infinitif : Je vais la voir.

Key words

  • pronom: un mot qui remplace un nom
  • COD: complément d'objet direct (qui? quoi?)
  • remplacer: to replace
  • éviter la répétition: avoid repeating
