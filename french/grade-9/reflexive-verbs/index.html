Reflexive verbs

Les verbes pronominaux : se lever, se brosser, s'habiller… pour la routine quotidienne.⁠​​‌​‌​​​​‌‌​​​‌‌​​‌​‌​​‌​‌‌​​‌‌​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​‌​‌​‌‌‌​‌​​​‌‌‌​​‌‌​‌‌​​​​‌​‌‌‌​‌‌​​‌‌​​‌​‌⁠ Grade 9 French.

Learn what you need to know

📝se lever : je me lève, tu te lèves, il/elle se lève, nous nous levons, vous vous levez, ils se lèvent
⏰se réveiller, se lever, se laver, se doucher
🪥se brosser les dents, se peigner, s'habiller
😴se coucher, s'endormir, se reposer
😊s'amuser, se dépêcher, s'appeler, s'entendre (avec)

Négatif : Je ne me lève pas. Passé composé avec être : Elle s'est levée. Infinitif : Je vais me coucher (le pronom change avec le sujet).

Key words

  • verbe pronominal: un verbe avec me, te, se, nous, vous
  • se dépêcher: to hurry
  • s'habiller: to get dressed
  • s'entendre avec: to get along with
