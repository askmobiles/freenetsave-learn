Learn what you need to know

Coding means writing instructions that a computer follows. Ontario includes coding in science, and many countries teach computer science in school.

An algorithm is a clear, step-by-step set of instructions to solve a problem, like a recipe.

➡️Sequence: steps in the right order
🔁Loop: repeat steps ("repeat 4 times")
❓Condition: if something is true, do this; else do that
📦Variable: a named box that stores a value, like score = 0
🐞Debugging: finding and fixing mistakes

Computational thinking means breaking a big problem into small parts (decomposition), spotting patterns, and leaving out unneeded details (abstraction).

Scientists code to control sensors, collect data, run simulations of weather and climate, and guide rovers on Mars.

Remember: sequence, loops and conditions are the building blocks of code.

Key words

  • algorithm: step-by-step instructions to solve a problem
  • loop: instructions that repeat
  • condition: an if-then choice in code
  • debugging: finding and fixing errors in code

See real-life examples

Thermostats

A thermostat follows a condition: IF the room is colder than 20 °C, THEN turn on the heat.

Traffic lights

Traffic lights run a loop: green, yellow, red, repeat. Sensors can add conditions for waiting cars.

Weather forecasts

Environment Canada uses supercomputers running huge programs to predict tomorrow's weather.
